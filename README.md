# Retail Sales Analysis Dashboard

## Project Overview
An exploratory analysis of retail sales data from the Sample Superstore dataset 
(9,800 rows), identifying key revenue drivers across product categories, customer 
segments, and regions using Excel pivot tables and charts.

## Business Questions Answered
- Which product category generates the most revenue?
- Which customer segment contributes most to sales?
- What are the seasonal sales trends across the year?
- Which region consistently outperforms others?
- What are the top 10 best-selling sub-categories?

## Tools Used
- Microsoft Excel (Pivot Tables, Charts, Dashboard)
- Dataset source: Kaggle — Superstore Sales Dataset

## Dataset
- **Rows:** 9,800 sales transactions
- **Period:** 2015–2018
- **Columns:** Order Date, Ship Mode, Segment, Region, Category, Sub-Category, Sales
